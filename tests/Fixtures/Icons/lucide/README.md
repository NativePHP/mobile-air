# Lucide icon fixtures

These SVGs are Lucide icons (lucide-react 1.57.0), rebuilt from each icon's
`__iconData.node` and wrapped in Lucide's default `<svg>` attributes. They are
used to test the custom icon converter against real-world input. In this
release `trash-2` is an alias of `trash`, so `trash-2.svg` holds `trash`.
